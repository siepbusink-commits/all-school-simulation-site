# All-School Simulation – GitHub Pages

Deze map bevat de openbare informatiepagina, privacyverklaring en gebruiksvoorwaarden.

## Publiceren met GitHub Pages

1. Upload de drie HTML-bestanden (`index.html`, `privacy.html`, `voorwaarden.html`) naar de hoofdmap van deze repository.
2. Open **Settings → Pages**.
3. Kies bij **Build and deployment** voor **Deploy from a branch**.
4. Selecteer branch `main` en map `/ (root)`, en klik **Save**.
5. Wacht tot GitHub Pages de site heeft gepubliceerd. De URL verschijnt op de Pages-instellingenpagina.

## Controle vóór publicatie

- Controleer of de naam van de juridische verantwoordelijke op de pagina's moet worden aangevuld.
- Controleer of het opgegeven contactadres geschikt is voor openbare ondersteuning.
- De privacytekst gaat uit van de huidige skills-only werking zonder eigen accounts, database, server, analytics of betalingen. Pas de tekst aan als dat verandert.
- GitHub Pages registreert volgens GitHub IP-adressen van bezoekers voor beveiligingsdoeleinden; dit is daarom in de privacyverklaring benoemd.
- Laat de juridische tekst zo nodig toetsen voordat je deze als definitieve juridische verklaring gebruikt.
